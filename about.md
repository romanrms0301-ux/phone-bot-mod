# Phone Bot Mod

Mod hecho para Geode en Android de 32 y 64 bits usando Geode v6.0.0-alpha.1 y Geometry Dash 2.2091

El proyecto incluye una base funcional mínima para cargar el mod, mostrar logs y usar una configuración llamada `bot-enabled`.

Actualmente está en fase de prototipo v1.0.2. Todavía no incluye un menú o un bot jugable dentro del juego.
